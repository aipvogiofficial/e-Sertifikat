# e-Serti AIPVOGI

Generator sertifikat AIPVOGI (narasumber, moderator, panitia, dan peran lain) berbasis PWA.
Data tersimpan di Google Sheet melalui Google Apps Script; tanda tangan dan stempel disimpan di Google Drive pribadi, bukan di repositori ini.

- Hasil: JPG dan PDF A4 landscape 300 dpi
- Nomor otomatis: `{urut}/AIPVOGI/Sek/{bulan Romawi}/{tahun}` dari tanggal pelaksanaan
- Dua admin, riwayat bersama, mode demo untuk mencoba

Generator sertifikat narasumber, moderator, panitia, dan lainnya

Pengaturan server

Mode demo menyimpan data hanya di perangkat ini, cocok untuk mencoba sebelum server dipasang.

Petunjuk penggunaan

  1. Kegiatan — tambahkan kegiatan: nama, tanggal, daring/luring, JPL, kota, dan nomor sertifikat untuk tiap peran (satu nomor untuk semua peserta, satu untuk narasumber, dst.).
  2. Buat Sertifikat — Satu per satu: pilih kegiatan dan peran (nomor terisi otomatis), ketik nama, lalu simpan + unduh. Banyak nama: unggah Excel berisi daftar nama peserta/panitia.
  3. Bagikan ke peserta — di tab Kegiatan, aktifkan halaman unduh peserta lalu salin link-nya ke grup WA. Peserta mencari namanya sendiri.
  4. Riwayat — cari, unduh ulang, atau perbaiki sertifikat. Setiap sertifikat memiliki QR untuk cek keaslian.

TTD dan stempel cukup diunggah sekali di tab Pengaturan oleh salah satu admin; semua admin otomatis memakainya.

Untuk Google Form + Autocrat

Unduh sertifikat tanpa nama untuk kegiatan dan peran di atas (nama penerima tidak perlu diisi). File ini tidak disimpan ke Riwayat dan tidak memiliki QR.

  1. Google Slides: File → Penyiapan halaman → Khusus 29,7 × 21 cm (A4 lanskap).
  2. Klik kanan slide → Ubah latar belakang → pilih gambar yang diunduh.
  3. Tambahkan kotak teks selebar slide berisi <<Nama>>: Arial tebal 24 pt, rata tengah, titik tengahnya ±9,4 cm dari atas (tepat di antara "Diberikan Kepada" dan "Atas Partisipasinya Sebagai").
  4. Gunakan slide itu sebagai template di Autocrat.
